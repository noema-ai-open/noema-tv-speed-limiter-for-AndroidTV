# Public Changelog — NOEMA TV Speed Limiter

## 1.2.5 — current closed Alpha

Current public test build distributed through Google Play.

Highlights:

- persistent local usage statistics and recent-session history
- active-session counters retained more reliably across interruptions
- live download-throughput display
- built-in diagnostics without ADB
- improved **Report problem** workflow with send/copy fallback
- visible screenshot/photo support fallback
- automatic limiter recovery after Wi-Fi/router reconnect
- improved streaming compatibility under connection-heavy startup conditions
- centered TV interface and remote-control usability refinements
- Android TV / Google TV App Bundle packaging
- 32-bit and 64-bit device support within the current Android target range

## Testing status

Broader compatibility testing is ongoing across Android TV / Google TV manufacturers, Android versions and streaming services.
