# Closed Alpha Testing

Thank you for testing NOEMA TV Speed Limiter on real Android TV / Google TV hardware.

## Join the test

https://play.google.com/apps/testing/ai.noema.tvspeed

## Recommended test sequence

1. Install NOEMA from Google Play.
2. Start the app and accept Android's VPN permission dialog.
3. Test **2 Mbit/s Saver** with a streaming service.
4. Test **4 Mbit/s Balanced**.
5. Test **6 Mbit/s Comfort**.
6. Select **Full Speed Home** and confirm unrestricted operation returns.
7. If practical, disconnect and reconnect Wi-Fi while a limited profile is selected.
8. Open NOEMA again and check statistics / diagnostics.

## Useful feedback

Please include:

- TV / box manufacturer
- exact model
- Android / Google TV version
- streaming service
- NOEMA profile used
- whether playback starts
- buffering or unexpected quality changes
- whether the remote control works naturally through the interface
- whether the limiter survives Wi-Fi/router reconnects
- any crash, freeze or VPN permission issue

## Reporting

For technical problems, use the app's **Report problem** function or email:

support@noema-ai.de

You can also open a GitHub issue in this public repository. Please do not post account credentials, private network credentials or other sensitive information.

## Distribution

The closed Alpha is distributed through Google Play only. This public repository does not provide APK downloads.
